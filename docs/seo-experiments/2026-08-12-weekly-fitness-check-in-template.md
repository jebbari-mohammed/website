# SEO Experiment: Weekly Fitness Check-In Template

- **Status:** launched
- **Launch date:** 2026-08-12
- **Target URL:** https://youraicoach.life/blog/weekly-fitness-check-in-template
- **Primary intent:** weekly fitness check-in template
- **Secondary intent:** weekly workout check-in template; fitness accountability check-in template
- **Action class:** new interactive search-entry asset
- **Owner:** ChatGPT senior SEO lead

## Evidence and rationale

Search Console's latest private summary exposed 5 query + landing-page rows, 7 impressions, and 0 clicks for 2026-07-15 through 2026-08-11. Exact queries were intentionally not printed, so this cold-start experiment relies on a live SERP task gap plus site relevance rather than pretending to have query-level evidence.

Current results for weekly fitness check-in templates are dominated by generic form builders, coach-facing downloads, and broad client questionnaires. IZEM's test is a no-signup, browser-only self-use tool that converts planned versus completed workouts, the repeated blocker, and one adjustment into a copyable weekly summary.

## Cannibalization check

No existing IZEM URL targets the exact template intent. Nearby pages serve different tasks:

- `/blog/fitness-app-that-reviews-your-day`: daily review/product-guide intent.
- `/blog/workout-accountability-ideas-alone`: broad accountability ideas.
- `/blog/accountability-apps-for-working-out`: app-comparison intent.
- `/workout-consistency-calculator/`: calculation and trend intent.

## Hypothesis

A private, interactive weekly fitness check-in template with a copyable 4P summary will earn discovery, indexing, impressions, and clicks for template/check-in searches while introducing relevant users to IZEM's active accountability loop.

## Baseline

- Dedicated target URL: did not exist.
- Target URL impressions: 0.
- Target URL clicks: 0.
- Site private GSC summary: 5 query/page rows, 7 impressions, 0 clicks.
- Priority URL inspection baseline: 4 of 7 indexed; 3 not yet crawled/indexed or unknown.

## Target metrics

1. Target URL becomes known to Google and indexed.
2. GSC impressions and query/page rows for the target URL increase from zero.
3. Organic clicks and average position establish a usable baseline.
4. Internal discovery remains intact from the blog archive and relevant guides.
5. Organic visitors reach the IZEM product CTA when conversion tracking is available.

## Expected direction

- Indexed status: unknown/new → discovered → indexed.
- Impressions: 0 → positive.
- Clicks: 0 → positive after impressions accumulate.
- Internal-link distribution: target receives crawlable links from discovery files and relevant pages.

## Review window

- **Preferred first decision date:** 2026-09-11 (30 days).

## Risks

- Search demand may be low despite attainable competition.
- Google may discover the URL slowly while the domain is still in cold start.
- Nearby accountability content requires careful anchoring so the new page remains template-first rather than becoming another generic app article.
