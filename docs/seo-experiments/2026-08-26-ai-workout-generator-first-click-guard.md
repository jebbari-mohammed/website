# SEO Experiment: AI Workout Generator First-Click Observation

- **Status:** launched
- **Launch date:** 2026-08-26
- **Target URL:** https://youraicoach.life/features/ai-workout-generator
- **Action class:** evidence preservation / index observability
- **Owner:** ChatGPT senior SEO lead

## Fresh first-party evidence

The verified Search Console window for 2026-07-29 through 2026-08-25 contains 63 private query + landing-page rows, 91 impressions, and IZEM's first recorded organic click.

The click landed on `/features/ai-workout-generator`. The page has 3 impressions in the current 28-day window and 1 click. One broad exact-intent impression reached the top 10. Exact query strings remain confined to the private evidence process.

The same Search Console health run inspected 25 priority URLs with 23 indexed, 0 explicitly not indexed, 2 neutral/unknown, and 0 URL Inspection API errors. The workout-generator feature page was not yet part of the fixed inspection set, so its crawl/index state depended on whether it won one of the adaptive GSC-visible slots.

## SERP review

Current broad AI-workout-generator results are heavily task-oriented. Multiple ranking pages provide an actual generator or a highly concrete plan-building flow using goal, schedule, equipment, level, and sometimes session duration or restrictions. Several winners also make progression/adaptation explicit rather than presenting a one-time generic routine.

That creates a plausible future product/tool opportunity for IZEM, but one click is not enough evidence to justify immediately replacing a page that has just demonstrated its first successful organic search outcome.

## Opportunity shortlist

1. **Protect and directly monitor the first-click feature page — chosen.** Highest confidence and lowest destructive risk. Preserve the current page, add it to fixed URL Inspection, and prevent overlapping material rewrites while the signal matures.
2. **Convert the feature page into an interactive free workout generator.** Strong SERP-format fit and potentially high upside, but materially higher engineering/content risk and premature from a one-click sample.
3. **Further optimize the workout-reminder page.** Its current 28-day visibility improved to 6 impressions at an average position of 28, but the August 24 material refresh is locked until September 14.
4. **Rewrite the progressive-overload comparison.** It still leads landing-page impressions, but the August 16 rehabilitation is protected until September 6 and should not be disturbed before recrawl/evaluation.
5. **Publish another new page.** Rejected because current evidence favors protecting and learning from URLs that are beginning to rank rather than adding another overlapping search entry today.

## Chosen change

- Add `https://youraicoach.life/features/ai-workout-generator` to the fixed Search Console URL Inspection priority set.
- Register the page in the active experiment lock registry through 2026-09-16.
- Make no title, description, H1, body, schema, canonical, sitemap, robots, CTA, or internal-link change to the target page.

The fixed inspection addition reduces adaptive GSC-selected inspection capacity by one slot under the 25-URL cap. That tradeoff is justified because this is now the only landing page with a verified organic click.

## Hypothesis

Preserving the current broad AI-workout-generator page while collecting direct crawl/index evidence will produce higher-quality learning than rewriting the page immediately after a single successful click. If impressions and top-20 visibility expand during the hold, the page becomes a strong candidate for a later interactive-tool upgrade. If the signal disappears, IZEM avoids spending a material content/engineering change on noise.

## Risks and limitations

- The current target-page sample is only 3 impressions and 1 click; CTR is not statistically meaningful.
- Fixing the page in the inspection set leaves fewer adaptive inspection slots for other GSC-visible URLs.
- SERP winners often expose a real generator, so a later hold decision may conclude that the current informational feature page has a format gap.
- The target page currently contains some older marketing language; it should not be cleaned up during the observation lock unless a factual, safety, legal, rendering, indexing, canonical, or deployment defect is confirmed.
