# SEO Experiment: Workout Accountability Agreement Template

- **Status:** launched
- **Launch date:** 2026-08-13
- **Target URL:** https://youraicoach.life/blog/workout-accountability-agreement-template
- **Primary intent:** workout accountability agreement template
- **Secondary intent:** fitness accountability agreement; workout accountability contract template
- **Action class:** new interactive search-entry asset
- **Owner:** ChatGPT senior SEO lead

## First-party baseline

The 2026-08-13 private Search Console health run returned 7 query + landing-page rows, 10 impressions, and 0 clicks for 2026-07-16 through 2026-08-12. Exact queries remain private and are not printed, so this experiment does not pretend GSC exposed this specific query.

The site remains in cold-start exploration. The target URL did not previously exist and therefore starts with 0 impressions and 0 clicks.

## SERP rationale

Live search for workout/fitness accountability agreement and contract variants showed a fragmented result set: a broad accountability-partner contract article, trainer-facing accountability guidance, and form-builder check-in templates. The gap is a self-use fitness-specific tool that lets a person define the workout commitment, check-in method, evidence rule, fallback after a miss, and review date without signup or a form-builder workflow.

## Cannibalization check

No existing IZEM URL targets the agreement/template task. Nearby URLs satisfy different intent:

- `/blog/workout-accountability-ideas-alone`: broad tactics for solo training.
- `/blog/accountability-apps-for-working-out`: app-comparison intent.
- `/blog/weekly-fitness-check-in-template`: retrospective weekly review/check-in intent.
- `/workout-consistency-calculator/`: planned-versus-completed calculation intent.

## Information gain

The page adds:

1. A browser-only accountability agreement generator.
2. The IZEM CLEAR framework: Commitment, Logistics, Evidence, Adjustment, Review.
3. A copy-and-paste blank agreement.
4. A worked example with a pre-decided fallback rule.
5. A decision table distinguishing agreements, check-ins, weekly reviews, and streaks.
6. Explicit safety boundaries and a non-legal/non-medical scope statement.

## Hypothesis

A fitness-specific, no-signup agreement builder will earn discovery and impressions for accountability-agreement/template searches while introducing high-intent consistency users to IZEM's proactive accountability model.

## Target metrics

1. Target URL becomes discovered and indexed.
2. Target URL impressions increase from 0.
3. Organic clicks increase from 0 after impressions accumulate.
4. Average position establishes a usable baseline for the primary and related intent cluster.
5. Organic visitors use the IZEM product path when conversion tracking is available.

## Expected direction

- Index status: new/unknown → discovered → indexed.
- Impressions: 0 → positive.
- Clicks: 0 → positive after visibility accumulates.
- Search-entry coverage for accountability templates: absent → present.

## Risks

- Exact search demand is not available from the private GSC summary.
